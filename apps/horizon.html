Tính Năng Cốt Lõi Của AISA Horizon

Được thiết kế tối ưu cho lập trình viên hiện đại, tích hợp chặt chẽ cùng AISA Orbit

🖥️ Giao Diện Dark Celestial

Tông màu vũ trụ thanh lịch, tương phản cao, dịu mắt khi lập trình xuyên đêm với bảng mã màu thương hiệu độc quyền MHEnt.

⚡ Liên Kết Chéo Cùng AISA Orbit

Mở phiên làm việc của Agent tự hành với 1 click. Chuyển đổi qua lại mượt mà giữa viết code tay và giao việc cho AI tự code.

🔐 Xác Thực MHEnt SSO

Đăng nhập liền mạch với tài khoản MHEnt Universe, đồng bộ quyền truy cập các mô hình AI Cloud và hồ sơ cá nhân.

🧩 Hệ Sinh Thái Extension

Hỗ trợ toàn diện kho tiện ích mở rộng, language servers cho TypeScript, Python, C++, Rust, Go, Web và nhiều ngôn ngữ khác.

🚀 Bộ Cài Đặt Độc Lập

Cài đặt nhẹ nhàng vào User Profile, không đòi hỏi quyền Admin phức tạp, tự động tạo lối tắt trên Desktop & Start Menu.

🛡️ An Toàn & Bảo Mật Tuyệt Đối

Đã loại bỏ các cảnh báo checksum không cần thiết, bảo toàn tính riêng tư của dự án với mã nguồn lưu trữ cục bộ.

Yêu Cầu Hệ Thống

Cấu hình đề nghị để trải nghiệm AISA Horizon mượt mà nhất

Cấu Hình Tối Thiểu

• Hệ điều hành: Windows 10 (64-bit) build 19041 trở lên
• Vi xử lý: 1.6 GHz hoặc nhanh hơn (x64 / AMD64)
• RAM: 4 GB RAM
• Ổ cứng: 1 GB dung lượng trống

Cấu Hình Khuyến Nghị

• Hệ điều hành: Windows 11 (64-bit)
• Vi xử lý: Đa nhân 2.5 GHz+ (Intel Core i5/i7/i9 hoặc AMD Ryzen)
• RAM: 8 GB - 16 GB RAM
• Ổ cứng: SSD với 5 GB dung lượng trống
